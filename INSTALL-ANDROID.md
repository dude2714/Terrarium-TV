# Install Terrarium TV on Android

1. Copy `Terrarium TV.apk` to your phone, tablet, Android TV, or TV box.
2. If you download it in a browser, tap the APK from the download notification or downloads list.
3. If prompted, allow installs from unknown apps for the app you used to open the file.
4. Confirm the install and wait for it to finish.

## TV Box Quick Path

1. Download the APK with a browser or copy it over with USB.
2. Open it with a file manager such as Files, X-plore, or a built-in downloads app.
3. Enable unknown-app installs for that file manager if Android asks.
4. Install the APK and launch it from your apps list.

## First Run Tip

- On Android TV or a TV box, the D-pad/remote should move focus automatically.
- If the interface feels cramped, use a mouse mode remote or an air mouse for easier navigation.

## Common Sources

- Browser downloads
- USB storage
- Local file manager
- Cloud download followed by a file manager open
